# ほめほめプレビューメイカー ⭐

褒めたいものを全力で褒めちぎって X に投稿する、**クチコミ風プレビュー画像メーカー**（お遊びツール）です。

アカウント名・褒めたいもの・レビュー文を入れると、レビュー文からポジティブワードを抽出して
**感情クラスタリング**し、いつもの「★5」の代わりに **絵文字 + ふざけた桁**（例: `🏡1兆` `😭無量大数`）を表示します。

## 使い方
1. アカウント名・褒めたいもの・レビューを入力
2. プレビューがリアルタイムに更新されます
3. 「🎲 引き直す」で絵文字と桁のバリエーションを変更
4. 「📤 Xにシェア」で画像ごと X へ（スマホは共有シート、PC は画像保存 + 投稿画面）
5. 「🖼 画像保存」「📋 コピー」も使えます

スマホではプレビューを「入力 / プレビュー」タブで切り替え、PC では左右に並べて表示します。

## 特徴
- **完全クライアントサイド**：入力は端末の外に一切送信されません（CSP `connect-src 'none'`）
- **依存ゼロ**：外部ライブラリ・CDN・ビルド不要。GitHub Pages にそのまま置けます
- 否定（「美味しくない」）や盛り上げ語（「本当に」「！」）も考慮

## ローカルで動かす
ES Modules を使うため、`file://` ではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## テスト
Node.js 20 以上で、追加インストールなしに実行できます。

```bash
npm test
```

## GitHub Pages で公開
Settings → Pages → Build and deployment → 「Deploy from a branch」→ `main` / `/(root)` を選択。
