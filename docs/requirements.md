# 要件定義書 — ほめほめプレビューメイカー

## 1. 目的
褒めたい対象（宿・店・人・モノなど）に対して、クチコミ風の「褒め褒めプレビュー」を作り、X（Twitter）に投稿して楽しむためのお遊びツールを提供する。
通常の「★5」の代わりに、レビュー文の感情に応じた **絵文字 + ふざけた桁の数値**（例: `🏡1兆`）を表示して笑いを生む。

## 2. 利用者
- X で友人・お店・推しを面白く褒めたい一般ユーザー（主にスマホ、PC・タブレットも）

## 3. 機能要件

| ID | 要件 | 優先度 |
|----|------|--------|
| F-01 | アカウント名を入力できる（最大 30 文字） | 必須 |
| F-02 | 褒めたいもの（タイトル）を入力できる（最大 40 文字） | 必須 |
| F-03 | レビュー本文を入力できる（最大 600 文字・改行可） | 必須 |
| F-04 | 入力に合わせてクチコミ風カードをリアルタイムにプレビューする | 必須 |
| F-05 | レビュー文からポジティブ語を抽出し、感情クラスタ（美味しさ・感動・懐かしさ等）ごとにスコアリングする | 必須 |
| F-06 | 最も強いクラスタを代表絵文字に変換し、★の代わりに表示する | 必須 |
| F-07 | 総スコアを「100 / 1000 / 1万 / 1億 / 1兆 / 1京 / … / 無量大数 / ∞」のような面白い桁に変換する | 必須 |
| F-08 | 否定表現（「美味しくない」等）はポジティブとして数えない | 必須 |
| F-09 | 盛り上げ語（「本当に」「まさに」「！」等）でスコアを増幅する | 推奨 |
| F-10 | 同じ入力なら同じ結果（決定的）。「引き直し」ボタンで絵文字・桁のバリエーションを変えられる | 推奨 |
| F-11 | 解析結果（クラスタ別スコア・検出語・倍率）を可視化する | 推奨 |
| F-12 | カードを PNG 画像として保存できる | 推奨 |
| F-13 | カード内容をテキストとしてクリップボードにコピーできる | 任意 |
| F-14 | 「Xにシェア」：スマホでは共有シートで画像ごと X アプリへ渡す。非対応環境では画像を保存し X の投稿画面を開く | 必須 |

## 4. 非機能要件

### 4.1 セキュリティ・プライバシー
| ID | 要件 |
|----|------|
| S-01 | 入力内容を外部に送信しない（サーバー・API・解析タグなし）。`connect-src 'none'` で強制する |
| S-02 | ユーザー入力を HTML として解釈しない（`innerHTML` 等を使わず `textContent` / Canvas で描画）＝ XSS 防止 |
| S-03 | Content-Security-Policy により自ドメイン以外のスクリプト・スタイル・インラインスクリプトを禁止 |
| S-04 | 外部ライブラリ・CDN・npm 依存を持たない（サプライチェーン攻撃の面を最小化） |
| S-05 | 入力長を制限し、制御文字・Unicode 双方向制御文字（表示偽装に使われる）を除去する |
| S-06 | 保存画像のファイル名に入力値を使わない |
| S-07 | リポジトリに秘密情報（API キー等）を含めない。CI は最小権限（`contents: read`） |
| S-08 | 脆弱性の報告窓口を `SECURITY.md` に明記する |

### 4.2 その他
| ID | 要件 |
|----|------|
| N-01 | GitHub Pages（静的ホスティング）だけで動作する。ビルド不要 |
| N-02 | 最新の主要ブラウザ（Chrome / Safari / Firefox / Edge）で動作する |
| N-03 | ダークモード対応（プレビューカードは保存画像と揃えるため常にライト） |
| N-04 | 感情解析ロジックは DOM 非依存で、Node.js 標準のテストランナーで単体テストできる |
| N-05 | ライセンスは MIT |

### 4.3 レスポンシブ（スマホ対応）
| ID | 要件 |
|----|------|
| R-01 | 幅 320px〜1440px 以上のすべてで横スクロールが出ない |
| R-02 | 〜879px（スマホ・タブレット縦）は「入力」「プレビュー」をタブで切り替える。プレビュータブに現在の判定（例: 🎐1京）を常時表示する |
| R-03 | 880px〜（タブレット横・PC）は入力とプレビューを 2 カラムで並べ、プレビューは追従表示する |
| R-04 | 操作ボタン（引き直す / Xにシェア / 画像保存 / コピー）は画面下に固定し、親指で押せる位置に置く |
| R-05 | タップ領域は 44px 以上。iPhone のホームバー等のセーフエリアを避ける |
| R-06 | 入力欄の文字サイズは 16px 以上（iOS のフォーカス時自動ズームを防ぐ） |
| R-07 | 文字サイズは画面幅に応じて伸縮する |

## 5. 対象外（スコープ外）
- 機械学習モデル・外部 AI API による感情解析（プライバシーとオフライン動作を優先）
- アカウント登録・投稿共有機能・サーバー側保存
- 実在の地図 / レビューサービスへの投稿連携

## 6. 受け入れ基準
- サンプル文（民宿のレビュー）を入れると「懐かしさ」クラスタが最上位になり、`🏡/🍊/📺/🎐` のいずれか + 兆以上の桁が表示される
- `<img src=x onerror=alert(1)>` を入力しても文字列としてそのまま表示され、スクリプトが実行されない
- `node --test tests/*.test.mjs` が全件成功する
- ブラウザコンソールに CSP 違反・エラーが出ない
- 320 / 390 / 768 / 1024 / 1440px の各幅で横スクロールが出ず、表示切り替えが仕様どおり動く
